## 三、执行清单（每次动手前照抄）

1. 我要改的东西，**现状是什么**？（先读文件，不靠记忆）
2. 我的**假设**能用什么**最小实验**证伪/证实？（拿到实证再动手）
3. 我**一次只改哪一处**？改完用什么命令校验？
4. 我要给这个改动配什么**测试/复核命令**？
5. 我汇报的四段写好了吗：**结论 / 证据 / 范围与影响 / 下一步**？
6. 我有没有触碰用户的硬禁忌？（**不弹窗、不抢焦点、不闪黑窗、不自动拉起**）
