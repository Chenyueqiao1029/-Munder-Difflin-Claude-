# 安装指南（给拿到这个项目的人）

> 你只需要 **Python 3.10+** 和一份 **Munder Difflin**（上游像素办公室应用）。
> 本项目是它的**二次开发**：只提供补丁与编排层，**不分发**上游的二进制与美术资源。

---

## 三步装好

```powershell
# 0) 先看环境能不能认到
python tools\md_config.py --check
```
- 输出 `app 定位: 成功 ✓` → 直接跳到第 2 步
- 输出 `失败 ✗` → 做第 1 步

### 1) 告诉它你的 app 在哪（二选一）

**方式 A：环境变量（临时）**
```powershell
$env:MD_APP_DIR = "D:\你的路径\Munder-Difflin-0.5.5-fixed"
python tools\md_config.py --check
```

**方式 B：写进配置文件（长期，推荐）**
```powershell
python tools\md_config.py --write      # 生成 config.json（不覆盖已有）
notepad config.json                    # 把 app_dir 改成你自己的路径
```
`config.json` 可改的字段（都有默认值，通常只改 `app_dir`）：

| 字段 | 含义 | 默认 |
|---|---|---|
| `app_dir` | 上游应用的安装根目录（**最重要**） | 自动探测 |
| `stage_dir` | 打补丁时的临时渲染目录 | `<app_dir>\_renderer-patched` |
| `pack_dir` | 补丁用的资源包目录 | `<仓库>\pack` |
| `renderer_dir` | app 的 renderer 目录 | `<app_dir>\resources\app\out\renderer` |
| `backup_dir` | 备份目录 | `<仓库>\backups` |
| `esbuild` | 语法门用的 esbuild 可执行文件 | 自动探测 |

> 环境变量优先级**高于** `config.json`：`MD_APP_DIR` / `MD_STAGE_DIR` / `MD_PACK_DIR` /
> `MD_ESBUILD` / `MD_RENDERER_DIR` / `MD_BACKUP_DIR`。

### 2) 先干跑一次（**不改任何文件**，看清楚它要改什么）

```powershell
python patches\patch_renderer.py --dry-run
python patches\patch_map.py --dry-run
```
两条都打印出"将要修改的文件清单"且退出码为 0 → 可以正式装。任何一条报"找不到 app" →
回到第 1 步检查 `app_dir`。

### 3) 正式安装

```powershell
python patches\patch_renderer.py     # 改前自动备份 + 过 esbuild 语法门，失败自动回滚
python patches\patch_map.py
```
装完**重启一次上游应用**即可看到效果。

## 一键验收（确认装对了）

```powershell
python tools\acceptance.py
```
它会依次跑：素材自检 → 形象上传（临时目录）→ 办公室上传（临时目录）→ 两个补丁干跑 →
"验收不新增脏文件"，最后给出 **PASS/FAIL 汇总**与退出码（全通过为 0）。

## 自定义你自己的形象与办公室

- **形象**：把人物立绘**拖到** `自定义形象.cmd` 上（或 `python tools\customize.py char 图片.png`）
- **办公室**：把俯视图**拖到** `自定义办公室.cmd` 上（或 `python tools\customize.py office 图片.png`）
- 详细说明与图片建议见 `docs\自定义指南.md`
- 尺寸规格与出图提示词见 `assets\ART-SPEC.md`、`assets\PROMPTS.md`

## 卸载 / 回滚

| 想撤销 | 怎么做 |
|---|---|
| 撤销补丁 | 把 `backups\` 或补丁脚本同目录下的 `*.bak-*` 复制回原名覆盖即可 |
| 撤销自定义办公室 | 把 `assets\map\office-atlas.backup-<时间>.png` 复制回 `office-atlas.png` |
| 撤销自定义形象 | 删掉 `assets\chars\<key>.*`，并从 `assets\custom-agents.json` 里删掉那一条 |
| 卸载天枢委派插件 | 见 `docs\插件-天枢委派.md`（把 profile 的 `*.bak-*` 还原 + 删 `node_modules\@starhive\dsh-subagent-tianshu`） |

## 常见问题

**Q：报"只读 / Permission denied"？**
A：从别处拷来的图片常带只读属性。工具已自动解锁；若仍失败，右键图片 → 属性 → 取消"只读"。

**Q：`--dry-run` 也报找不到 app？**
A：说明自动探测没命中。按第 1 步显式设 `MD_APP_DIR` 或写 `config.json`。

**Q：我会不会把上游改坏？**
A：不会。补丁脚本**改前备份、改后过语法门、失败自动回滚**；而且**只改 renderer 的产物**，
不碰上游的资源文件。

**Q：可以只跑一半吗？**
A：可以。两个补丁互相独立，只装 `patch_renderer.py` 也能用。
