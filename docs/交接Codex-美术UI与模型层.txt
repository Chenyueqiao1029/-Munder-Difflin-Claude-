第 0 节 · 一句话
---------------
把「像素美术层」做成一个与后端框架解耦的【上层 UI 层】：任何 Agent 框架（我们的 7 个 / oh-my-coder
的 31 个 / 以后 100 个）只要产出一份清单，就能套上这层皮；同时保证「能在终端里看到它们对话」。
美术本身由老板用 AI 出图（我们只出提示词 + 规格 + 自检），不承担画图。

1.6 自定义模型（老板上传图即可）
    文件：tools/add_custom_agent.py
    命令：python tools\add_custom_agent.py --image D:\我的图.png --name "我的模型" --key mymodel --model glm --install
    行为：自动抠纯色/棋盘格背景 -> 裁到内容 -> 生成 <key>.sheet.png（504x324）+ <key>.portrait.png
          （144x216）-> 追加登记 assets/custom-agents.json -> 自动调用自检
          不加 --install 就只生成与登记，不动办公室
    实测：mymodel 生成并通过自检（0 失败）
    已知限制：上传「全身立绘」效果最好；只给头像时走路帧只能是复制的（自检会提示），仅可当占位。
    提交：2b4c7e9

第 3 节 · 硬约束（违反会毁掉已完成的工作）
------------------------------------------

1) 禁止弹窗 / 抢焦点 / 自动开浏览器 / 覆盖桌面（老板在桌面一打游戏，AI 在桌面二工作）

   键盘事件有效但盲点鼠标危险。相关结论：截图 3 次点击后画面字节完全一致。
3) 不要动比赛仓库 E:\Downloads\lingshu-server

   不要重建 renderer（U2 补丁与对话终端注入是就地改的，重建会丢）
5) 主进程补丁：__mdPtyBind / __mdAutoRevive / __mdWakeForce（__mdWakeRestart 已移除），
   改完要过 esbuild 语法门并留备份
6) 禁止在 outbox 写 act="done"（会被 app 当临时工完工信号回收）；完工用 act="inform"
7) Windows/PowerShell 5.1 环境：不要用 Set-Content 写 JSON（BOM 致命）；
   用命令行为关键字过滤进程时必须排除自身 PID（我因此误杀过 harness 自己的进程两次）
8) 本仓库所有脚本都做过「无窗口」处理（CREATE_NO_WINDOW + pythonw），新增脚本请照做
