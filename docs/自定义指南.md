# 自定义指南（给普通用户）

> 不用懂代码，不用改任何文件。**选一张图，拖到对应的 .cmd 上，就行。**

---

## 一、换形象（给自己加一个 AI 员工 / 换个角色样子）

1. 准备一张**人物立绘**（PNG/JPG 都行；**全身**最好，正面朝镜头；背景纯色或透明更好抠）
2. 把这张图**拖到** `自定义形象.cmd` 上（或双击它，再点选图片）
3. 看屏幕输出：
   - `✓ 通过` → 成功，产物在 `assets\chars\<名字>.sheet.png` + `.portrait.png`
   - 提示"脚底没贴底 / 头顶留白" → 不阻塞，可以先用
   - 提示"尺寸不对 / 全透明" → 换一张图

**它自动做了什么**：抠背景 → 裁到人物 → 缩放进引擎格子（72×108）→ 排成引擎要的
3 行（正面/背面/侧面）× 7 列（走路 4 帧 + 站立/工作/阅读）→ 另出一张 144×216 头像。

> 想让新角色**真的出现在办公室里**，再加一步（可选）：
> 双击 `自定义形象.cmd` 时它会问你要不要装；或命令行加 `--install`。

---

## 二、换办公室（整间场景换成你自己的图）

1. 准备一张**俯视图**（斜 45° 或正俯视都行；正方形/横图都行；**越大越清晰**）
   - 建议：地面的颜色**偏亮且平整**（会被判定"能走"），墙/家具**偏暗或有花纹**（会被判定"不能走"）
   - 建议边长是 **16 的整数倍**（不是也行，会自动裁到整数倍）
2. 把图**拖到** `自定义办公室.cmd` 上
3. 看输出，它会做三件事：
   - 生成图集 `assets\map\office-atlas.png`（旧图自动备份成 `*.backup-<时间>.png`）
   - 生成地图 `assets\map\office-map.json`（50×37 格那种，含"能走/不能走"两层）
   - **自动排 12 个工位** → `assets\map\office-seats.json`（想调位置直接改里面的 x/y）
4. 满意后，再加 `--install` 装进办公室（会先备份 + 过语法门）：
   ```
   python tools\customize.py 办公室 D:\我的办公室.png --install
   ```

**不满意想还原**：把 `assets\map\office-atlas.backup-<时间>.png` 改回 `office-atlas.png` 即可。

---

## 三、图片怎么给最好用（一张图看懂）

| 项 | 换形象 | 换办公室 |
|---|---|---|
| 内容 | **一个人**的全身立绘 | 一间屋子的**俯视图** |
| 视角 | 正面朝镜头（会生成背面/侧面） | 俯视或 45° |
| 背景 | 纯色 / 透明（自动抠） | 不透明也行 |
| 尺寸 | 越大越清晰，建议 ≥ 300×450 | 建议 ≥ 800×600 |
| 别这样 | 多人合影、纯头像、人物被裁一半 | 带文字水印、透视很夸张 |

## 四、常见问题

**Q：报 `Permission denied` / `只读` ？**
A：从别处拷来的图常带只读属性，工具已经会自动解锁。若还失败，右键该图片属性 → 取消"只读"。

**Q：人物被切成两半 / 少了半个身子？**
A：多半是原图里**多个角色挨得太近**，或角色**贴着格子边**。换一张"一个人、四周留白"的图即可。

**Q：一次能加几个人？**
A：不限。形象工具会不断往 `assets\custom-agents.json` 里追加，加多少个都行。

**Q：出图前想自己画/让 AI 画，有没有规格？**
A：有，看 `assets/ART-SPEC.md`（尺寸、行列、禁止项、中英双语提示词模板）。
想按现成案例画，看 `assets/PROMPTS.md`（16 个 AI 品牌的提示词）。

**Q：我改了 `office-seats.json` 的坐标，为什么没生效？**
A：要先让补丁重新读一遍（`python tools\customize.py 办公室 <图> --install`），或直接改完再跑一次安装。

## 五、给开发者

- 入口：`tools/customize.py`（`char` / `office` 两个子命令）
- 形象：`tools/add_custom_agent.py`
- 办公室：本工具自己就是一个完整实现（图集 + Tiled 地图 + 工位），
  也兼容老的 `art/build_map2.py` + `patches/patch_map.py` 路线
- 规格自检：`art/check_assets.py`（8 项硬性检查）
- 批量派生：`art/recolor_cast.py`（7 个基础角色 → 任意 N 个配色变体）
- 预览验收：`tools/preview_cast.py`（切完拼接触表，肉眼检查抠图质量）
